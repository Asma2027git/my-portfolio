# Asma Creative Portfolio — Local Preview V2

Built with Streamlit using actual files from `projects.zip`. Nothing is published.

## Run in the existing VS Code terminal

```powershell
streamlit run app.py
```

If setting up a fresh environment, use `python -m venv .venv`, activate it, then `pip install -r requirements.txt`.

## What changed

- Eight project groups, reflecting actual supplied work.
- Four videos are playable within their respective project details.
- Ten graphic assets are displayed within grouped campaigns.
- The 7-page Markazia UX PDF has preview screens and is downloadable.
- All media stored locally in `assets/`.

## Before publishing

Confirm name, project titles/attribution, descriptions, permission to publicly showcase client work, and contact details. The displayed wording is descriptive, not a claim about Asma's exact role in each project.
